# Summary

Czech-PDTSC is based on the spoken (PDTSC) portion of Prague Dependency Treebank - Consolidated 2.0 (PDT-C),
created at the Charles University, Prague. It contains transcriptions of spontaneous dialogs from the
Malach and Companions projects.
